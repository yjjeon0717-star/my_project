# 🎄 Merry Christmas - One-Page Interactive Holiday Website

감성적이고 따뜻한 크리스마스 분위기를 가득 담은 원페이지 인터랙티브 크리스마스 웹사이트입니다.

---

## ✨ 주요 기능 및 특징

1. **❄️ 인터랙티브 눈 내리는 밤하늘 (Canvas Physics)**
   - 마우스 움직임에 따라 바람의 방향과 속도가 반응하는 부드러운 60fps 눈송이 효과
   - 상단 네비게이션의 `화이트 크리스마스` 버튼으로 폭설 모드 전환 가능
   - 밤하늘을 수놓는 오로라 그라데이션 및 반짝이는 별빛 애니메이션
   - 밤하늘을 날아가는 루돌프와 산타클로스의 썰매 애니메이션

2. **⏳ 실시간 크리스마스 D-Day 카운트다운**
   - 12월 25일 00:00:00까지 남은 일, 시간, 분, 초를 실시간 계산하여 부드럽게 갱신

3. **🌟 인터랙티브 소원의 크리스마스 트리 (Wish Tree)**
   - 트리에 장식된 반짝이는 오너먼트(별, 벨, 쿠키 등)를 클릭하여 다른 사람들의 따뜻한 소원 확인
   - 사용자가 직접 오너먼트 종류와 작성자명, 소원 메시지를 입력하여 트리에 달 수 있는 폼 제공
   - `LocalStorage` 자동 연동으로 새로고침해도 소원이 영구 보존됨
   - 트리 상단의 찬란한 골든 스타를 클릭하면 특별한 아르페지오 종소리가 울림

4. **🔮 신비로운 스노우볼 (Magical Snow Globe)**
   - 동화 속 오두막, 눈사람, 침니 연기가 들어있는 3D 입체 유리 구슬 디자인
   - 클릭하거나 "스노우볼 흔들기" 버튼을 누르면 구슬이 흔들리며 격렬한 눈보라가 소용돌이침
   - 맑고 영롱한 크리스마스 벨 차임 사운드 효과 연동

5. **🎁 두근두근 어드벤트 럭키 박스 (Surprise Holiday Gifts)**
   - 설렘, 쉼과 평온, 사랑, 기적의 4가지 테마 선물 상자
   - 클릭 시 뚜껑이 열리는 3D 애니메이션과 함께 따뜻한 연말 축복 메시지 및 행운 지수 공개

6. **💌 나만의 크리스마스 엽서 제작소 (Postcard Generator & Export)**
   - 4가지 무드 테마 선택 (클래식 레드, 포레스트 그린, 미드나잇 스카이, 골든 샴페인)
   - 실시간 입력 반영 프리뷰 (To, Message, From, 우표, 실링 왁스 인장)
   - **원클릭 메시지 복사** 기능
   - **고해상도 엽서 이미지 다운로드(PNG)**: HTML5 Canvas 기반으로 실시간 렌더링되어 파일로 즉시 저장

7. **🔥 벽난로 라운지 & 오르골 캐럴 연주기 (Web Audio API)**
   - 외부 오디오 파일 다운로드 없이 브라우저 자체 Web Audio API 신디사이저로 구현된 맑은 오르골 사운드
   - 3곡의 대표 캐럴 수록:
     - *Jingle Bells*
     - *We Wish You A Merry Christmas*
     - *Silent Night (고요한 밤 거룩한 밤)*
   - 타닥타닥 타오르는 따뜻한 벽난로 장작 소리 효과음 토글

## 🚀 실행 방법

### 방법 1. 브라우저로 바로 열기
별도의 서버 설치 없이 `index.html` 파일을 더블 클릭하여 Chrome, Edge, Safari, Firefox 등 원하는 브라우저에서 바로 실행할 수 있습니다.

```bash
# Windows 탐색기에서 현재 폴더 열기
explorer .
```

### 방법 2. 로컬 웹 서버로 열기 (선택 사항)
Node.js 환경인 경우 아래 명령어로 간편하게 로컬 서버를 구동할 수 있습니다.

```bash
npx serve .
# 또는 VS Code의 'Live Server' 확장 프로그램 사용
```
